# Security

`/.well-known/josh` is intentionally public. It must never contain credentials, private profile data, access tokens, or anything else that depends on confidentiality.

If you find a security issue in the WordPress plugin, please use GitHub's private vulnerability reporting for this repository once the public repository is available. Do not open a public issue containing working exploit details before there has been a reasonable opportunity to review and fix the problem.

Security issues in the Joshternet protocol itself belong in the specification project rather than being patched into this plugin as undocumented WordPress-only behavior.
